# Hi, I'm Abhishek 👋

Software Engineer at MapmyIndia and MCA graduate, passionate about building scalable applications and exploring the rapidly evolving world of Artificial Intelligence.

With experience across both frontend and backend development, I specialize in creating modern, responsive, and high-performance applications using React.js, Next.js, Angular, Node.js, Go, and the MERN and MEAN stacks. I enjoy designing clean architectures, building robust APIs, and delivering solutions that solve real-world problems.
